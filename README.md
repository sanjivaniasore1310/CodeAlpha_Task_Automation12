# 📂 Image File Automation using Python

## 🏆 Internship Project Submission

---

## 📌 Project Overview

The **Image File Automation Script** is a Python-based automation tool designed to organize image files automatically.

This script scans a source folder, identifies image files, and moves them to a separate destination folder while preventing duplicate file overwriting.

The project demonstrates practical implementation of file system automation using Python.

---

## 🎯 Objectives

* Automate repetitive file organization tasks
* Move image files automatically
* Prevent file overwriting
* Improve efficiency in file management

---

## 🚀 Features

✔ Automatically creates required folders
✔ Moves all image formats (`.jpg`, `.jpeg`, `.png`, `.webp`)
✔ Handles uppercase & lowercase extensions
✔ Prevents duplicate file overwriting
✔ Displays total number of files moved
✔ Clean and crash-free execution

---

## 🛠 Technologies Used

* Python 3
* os module
* shutil module
* File handling

---

## 🧠 Concepts Implemented

* Directory traversal using `os.listdir()`
* Path management using `os.path.join()`
* File moving using `shutil.move()`
* Extension filtering
* Duplicate file handling logic
* Conditional checks & loops
